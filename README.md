# Structured Query Language (SQL)

- SQL is a language for retrieving and analyzing data from large databases, especially when you need fast, structured queries.
- SQL fetches, filters, groups, and joins data, but it does not change the underlying database unless you explicitly run commands like INSERT, UPDATE, or DELETE.
- SQL is universal across many database systems, meaning the same core commands work whether you use MySQL, PostgreSQL, SQL Server, or SQLite.
- To use SQL, you typically need a database system (such as MySQL) and a tool to run queries (such as MySQL Workbench).
- To import Excel files into MySQL, files needs to be saved as CSV format. MySQL Workbench’s “Table Data Import Wizard”  is used to to load CSV.
